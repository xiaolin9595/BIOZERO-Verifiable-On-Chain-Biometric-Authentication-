# BIOZERO: Verifiable On-Chain Biometric Authentication

This repository contains the experiment code and compact evidence used to reproduce the BioZERO evaluation. It includes the quantization experiments, Circom/Groth16 protocol benchmarks, the complete-verifier gas experiments, the seven-size CircuitCheck/Vanilla sweep, and the scripts that assemble and verify the paper tables and Fig. 3.

## Repository layout

| Path | Purpose |
|---|---|
| `experiments/quantization/` | Face-embedding quantization and recognition experiments |
| `experiments/protocol-current/` | Circom circuits, Solidity verifiers, benchmark drivers, controls, and compact result summaries |
| `experiments/circuitcheck-grid/` | CircuitCheck experiment for `N={2,4,8,16,32,64,128}` |
| `experiments/circuitcheck-vs-vanilla/` | Controlled Vanilla ZoKrates and CircuitCheck comparison harness |
| `experiments/fig3-full/` | Fig. 3 aggregation, verification scripts, and final summary data |
| `paper/analysis/` | Scripts that verify claims and generate paper tables/Fig. 3 |
| `paper/data/` | Compact machine-readable reproduced measurements |

## Quick starts

### Protocol and complete-verifier benchmarks

```bash
cd experiments/protocol-current
npm ci --ignore-scripts --no-audit --no-fund
node scripts/generate-inputs.mjs
npm run reconstruct:setup
BIOZERO_REPETITIONS=5 npm run benchmark:packed
npm run benchmark:complete
node scripts/verify-reproduction.mjs
```

The setup command creates fresh single-party benchmark keys. They are for local measurements only and must not be used in production.

### CircuitCheck seven-size sweep

```bash
cd experiments/circuitcheck-grid
npm ci --ignore-scripts --no-audit --no-fund
npm run experiment
```

For a lightweight compile/witness check:

```bash
npm run smoke
```

### Inspect the assembled Fig. 3 evidence

```bash
cd experiments/fig3-full
python3 -m json.tool results/verification.json
python3 -m json.tool results/summary.json
```

This public package keeps the aggregate results and verification record. The
original full-bundle verifier is retained for audit documentation, but its raw
process logs, proof material, and host snapshots are deliberately omitted.

See each experiment directory's README or runbook for its pinned toolchain, measurement protocol, and expected outputs.

## Deliberately omitted artifacts

The repository excludes generated `node_modules`, compiled circuits, powers-of-tau transcripts, proving keys, witnesses, raw biometric images/templates, model weights, and multi-gigabyte build caches. These files are either regenerated by the provided scripts, externally sourced under their own terms, or inappropriate to publish. Compact JSON/CSV summaries and hashes are included for auditability.

## Security notice

This is research benchmark code. The local trusted setups, stand-in circuits, deterministic test material, and benchmark contracts are not production deployments. Do not reuse generated keys or deploy the benchmark contracts with real biometric data.
